Motion — one clock for every transition Every duration in the engine is calc(var(--cfg-motion) × …). The clock has three settings and one override; the toolbar's Off · On · Debug stamps it on this site.
Stamp--cfg-motionWhat it means
data-ui-motion="on"1the designed timing
data-ui-motion="off"0every transition instant — the person asked for stillness
data-ui-motion="debug"10ten times slower — the anatomy of a cross-fade, a drawer, a rail collapse, visible for study (an operator's tool)
@media (prefers-reduced-motion: reduce)0the operating system's preference wins over every stamp, debug included
The stamp rides <html>: here the toolbar sets it, in an app a stored preference the server renders. The rule that makes the OS win is one line in the engine's theme layer: @media (prefers-reduced-motion: reduce) { :root, [data-ui-motion] { --cfg-motion: 0 } }. There is no per-component clock to forget.
